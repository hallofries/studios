OBLOR SIMPLE DESKTOP

This is the stripped-down HTML/CSS/JS version.
No React, no Vite, no npm, no build step.

FILES:
- index.html   = structure + all JavaScript
- oblor.css    = XP styling
- assets/      = XP assets copied from the React XP reference repo

TO CUSTOMIZE:
1. Replace assets/wallpaper.jpg with your final wallpaper.
2. Replace assets/oblor-icon.png with the final OBLOR.exe icon.
3. Edit folderData inside index.html to add your real Process / Sketches / Pictures files.
4. Put the Godot web export into a folder named game/ beside index.html.
   OBLOR.exe already points to game/index.html.

The olive window and taskbar gradients, titlebar button sprite, desktop icon treatment,
and notification styling were taken from the React XP project you supplied and simplified
into ordinary HTML/CSS/JS.
